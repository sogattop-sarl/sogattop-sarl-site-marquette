# Site web SOGATTOP SARL

Site vitrine statique en HTML, CSS et JavaScript.

## Fichiers
- `index.html` : contenu des pages et informations de référencement.
- `styles.css` : mise en page et design responsive.
- `script.js` : menu mobile et année automatique.
- `assets/` : emplacement des photos, du logo et des documents à ajouter.

## Modifier les informations
Ouvrir `index.html` dans un éditeur de texte (par exemple Visual Studio Code ou Bloc-notes) pour modifier les textes, services, téléphone et coordonnées.
Modifier `styles.css` pour changer les couleurs et la présentation.
Ajouter les photos dans `assets/`, puis les référencer dans `index.html`.

## Publication avec GitHub Pages
Dans le dépôt GitHub : Settings > Pages > Build and deployment > Deploy from a branch.
Choisir la branche `main` et le dossier `/ (root)`, puis Save.
Le site sera publié à l'adresse indiquée par GitHub Pages.

## Référencement Google
Le site contient un titre, une description, des métadonnées de partage et des données structurées de type ProfessionalService.
Après publication, ajouter le domaine dans Google Search Console et soumettre le sitemap lorsqu'un sitemap sera créé. L'indexation par Google n'est pas immédiate ni garantie.

## Logo
Le logo vectoriel est dans `assets/logo-sogattop.svg`. Il pourra être remplacé par une version officielle validée ultérieurement.
